Deepfake Detection (Frequency-Domain CViT)

The production pipeline splits preprocessing into a spatial branch (RGB patches) and a frequency branch (2D-FFT / DCT magnitudes, where GAN upsampling leaves periodic fingerprints), fused by a Convolutional Vision Transformer. This demo reimplements the frequency branch honestly in JavaScript: pick any real or fake sample, inspect its magnitude spectrum and DCT energy, and see the detector's verdict with an interpretability overlay — then check the ROC over a seeded evaluation set.

Architecture

Raw video/image → Frame extraction (OpenCV in prod) → Preprocessing branch split ├─ Spatial: normalized RGB patches └─ Frequency: 2D-FFT / DCT magnitude per patch ← reimplemented here → CViT backbone: CNN stem → Transformer encoder ← spectral scorer here → Classification head: real/fake + confidence → Grad-CAM + spectrum visualization ← attribution overlay here ↓ Eval: ROC-AUC · cross-dataset generalization (train FF++ → test Celeb-DF)
Production mapping. Training uses FaceForensics++ with Celeb-DF held out; the FastAPI inference endpoint accepts a video and returns per-frame heatmaps. This demo's synthetic generator (smooth 1/f² texture = "real", plus a periodic fingerprint = "fake") is a controlled stand-in so the whole frequency-domain pipeline is inspectable without a GPU.
